# Roblox Stage (ระบบเวทีรับคิวจากไลฟ์)

เกม Roblox ที่ให้คนดูไลฟ์ TikTok พิมพ์ชื่อ Roblox ในแชท แล้วตัวละครของเขาขึ้นไปเต้นบนเวที ของขวัญที่ส่งมาจะต่อคิวเอฟเฟกต์
ประกอบด้วย 3 ส่วน: **ไฟล์เกม** (`build/DanceStage.rbxlx`), **สคริปต์เกม** (`src/`) และ **ตัวกลาง TikTok** (`bridge/`)

## เปิดเกมใน Roblox Studio (วิธีเร็วที่สุด)
1. ดาวน์โหลดไฟล์ `roblox-stage/build/DanceStage.rbxlx` แล้วดับเบิลคลิกเปิดใน Roblox Studio
   (ฉากธีมฮาโลวีนถูกอบมาในไฟล์ เปิดแล้วเห็นเวทีทันที)
2. กด **Play** (F5) กล้องจะล็อกมองเวที และมีแผง **Stage test panel** มุมซ้ายบน
3. ลองใช้แผง: พิมพ์ชื่อ Roblox แล้วกด **Join stage**, กดปุ่มของขวัญ (Rose / Lion / Galaxy), กดปุ่มธีมเพื่อเปลี่ยนแมป
4. หรือพิมพ์ในแชท: `/join <ชื่อRoblox>`, `/gift Rose`, `/theme DiscoNeon`
   (ถ้าคำสั่งแชทไม่ตอบสนอง ให้ใช้แผงแทน เพราะอาจขึ้นกับระบบแชทของ Roblox)

แผงทดสอบและคำสั่งแชทใช้ได้เฉพาะใน Studio และเจ้าของเกมเท่านั้น คนดูทั่วไปใช้ไม่ได้

## ธีมของแมป
มี 3 ธีมให้เลือก: **Halloween** (ค่าเริ่มต้น), **DiscoNeon**, **Simple**

| วิธีเปลี่ยน | ทำอย่างไร |
|---|---|
| ค่าเริ่มต้นของเกม | แก้ `Theme = "..."` ใน `src/server/Config.luau` |
| ระหว่างทดสอบ | ปุ่มธีมในแผงทดสอบ หรือ `/theme <ชื่อ>` |
| ระหว่างไลฟ์ | การ์ด "ธีมแมป" ในแอปตัวกลาง (ต้องเผยแพร่เกมและเปิดเซิร์ฟเวอร์ไว้) |
| ดูตัวอย่างตอน Edit (ไม่ต้องกด Play) | Command Bar: `require(game.ServerScriptService.Stage.ThemeManager).apply("DiscoNeon")` |

เพิ่มธีมใหม่: คัดลอกบล็อก `Themes.Halloween` ใน `src/server/Themes.luau` แล้วเปลี่ยนชื่อและค่า (แสง, พื้นเวที, ของตกแต่ง, กล้อง)
ชนิดของตกแต่งที่มี: Pumpkin, Candle, Pillar, DeadTree, Moon, Spotlight, NeonTile, DiscoBall
ธีมใหม่จะโผล่ในแผงทดสอบและแอปตัวกลางเอง

## เอฟเฟกต์ของขวัญ
ตั้งค่าใน `Gifts` ของ `src/server/Config.luau` (ชื่อของขวัญตอนนี้เป็นชื่อตัวอย่าง ต้องแก้ให้ตรงกับของขวัญ TikTok จริง)

| ขนาด | ชื่อตัวอย่าง | เอฟเฟกต์ | ผลที่เกิด |
|---|---|---|---|
| เล็ก | Rose | `Hearts` | หัวใจลอยขึ้นเหนือคนที่เต้นล่าสุด |
| เล็ก | TikTok | `Spotlight` | สปอตไลต์ส่องคนที่เต้นล่าสุด 6 วินาที |
| กลาง | Lion | `Giant` | ตัวละครขยายเป็น 2 เท่า 8 วินาที แล้วค่อยหดกลับ (+เวลาอยู่บนเวที) |
| ใหญ่ | Galaxy | `Fireworks` | พลุ 6 ลูกทั่วเวที (+เวลาอยู่บนเวที) |
| ใหญ่ | Universe | `ThemeSwap` | เปลี่ยนธีมแมปเป็น DiscoNeon 30 วินาที แล้วกลับ (ส่งซ้ำจะต่อเวลา) |
| ใหญ่ | Interstellar | `QueueJump` | ซื้อรัดคิว: ข้ามไปหัวแถว (ถ้ายังไม่ได้พิมพ์ชื่อ การพิมพ์ครั้งถัดไปภายใน 2 นาทีจะได้ก่อน) และคนที่เหลือเวลาน้อยที่สุดจะออกเร็วขึ้น |

กติกา: เอฟเฟกต์เล่นพร้อมกันได้ไม่เกิน `MaxActiveEffects` (3) ที่เหลือรอในคิว
"ซื้อรัดคิว" ผูกกับคนที่ส่งของขวัญ (ชื่อ TikTok เดียวกับที่พิมพ์ชื่อ Roblox ในแชท)

## ควบคุมกล้อง
กล้องเริ่มต้นตามธีม แล้วคนไลฟ์ขยับได้ระหว่างเล่น (ตัวละครของคนไลฟ์จะไม่เดิน อินพุตทั้งหมดถูกใช้ขยับกล้องแทน):

| อุปกรณ์ | วิธี |
|---|---|
| จอยเกม | แท่งซ้าย/ขวา = หมุนรอบเวที, แท่งขวาขึ้นลง = เงยก้ม, L2/R2 = ซูมออก/เข้า, กดแท่งขวา (R3) = รีเซ็ต |
| คีย์บอร์ด | A/D = หมุน, W/S = ซูม, กดเมาส์ขวาค้างแล้วลาก = หมุนและเงยก้ม, ล้อเมาส์ = ซูม, R = รีเซ็ต |
| มือถือ | จอยสติ๊กบนจอทำงานเหมือน WASD และมีปุ่มกล้องในแผง (◀ ▶ ▲ ▼ ＋ － ⟲) |

## แผงทดสอบในเกม
แผง **Stage panel** มุมซ้าย: กดหัวแผง (▾/▸) เพื่อหุบ หรือกด **H** เพื่อซ่อนทั้งแผง (แผงจะติดในภาพไลฟ์ถ้าไม่ซ่อน)
ระหว่างไลฟ์จริงให้ใช้แอป local แทน: มีปุ่มทดสอบของขวัญทุกชนิดและปุ่มเปลี่ยนธีม และการ์ดทุกใบหุบได้
(จอยสติ๊กกล้องต้องทำงานในเกมโดยตรง ส่งผ่านแอป local ไม่ได้ เพราะ MessagingService มีความหน่วงหลายวินาที)

## เรื่องความสวยของแมป
แมปสร้างจากพาร์ตพื้นฐาน (กล่อง ทรงกลม กระบอก) ด้วยโค้ด ไม่มีโมเดล 3 มิติหรือเท็กซ์เจอร์ที่ศิลปินทำ จึงดูเรียบกว่าแมปของโปรเจกต์ที่ใช้ทรัพยากรสำเร็จรูป
สิ่งที่ปรับเพิ่มแล้ว: แสง Future (เงาจากไฟจริง), ปรับสี, เบลอฉากหลัง, หมอก, หลุมศพ, รั้ว, เส้นนีออนบนพื้น
ถ้าอยากได้ระดับที่ดูดีกว่านี้ วิธีที่ได้ผลคือเอาโมเดลสำเร็จรูปจาก Creator Store (เช่นชุดฉากฮาโลวีน, สกายบ็อกซ์) มาวางแทนของตกแต่งชุดนี้

## สิ่งที่ตรวจสอบแล้ว และสิ่งที่ยังไม่ได้ตรวจสอบ
ตรวจสอบแล้ว (รันอัตโนมัติด้วย `cd tools && npm install && npm run verify`):
- สคริปต์ Luau ทุกไฟล์คอมไพล์ผ่าน
- สคริปต์รันบน Luau VM จริงกับ Roblox API จำลอง ชื่อ property / enum / ชนิดค่า ถูกตรวจกับฐานข้อมูล API ของ Roblox
  และตรวจรูปทรงแมป (เสาตั้งตรง, สปอตไลต์หันเข้าเวที ฯลฯ) กับข้อความที่ตัวกลางส่งเข้าเกม (รวมข้อความผิดรูปแบบ)
- ไฟล์ `.rbxlx` อ่านกลับมาได้ครบ และเนื้อสคริปต์ตรงกับไฟล์ต้นฉบับทุกตัวอักษร
- ตัวกลาง Node.js ผ่านเทสต์อัตโนมัติ (`cd bridge && npm test`)

**ยังไม่ได้ตรวจสอบ** (ผมไม่มี Roblox Studio ในการพัฒนา ต้องลองเอง):
- ไฟล์ `.rbxlx` ยังไม่เคยถูกเปิดใน Roblox Studio จริง รวมถึงหน้าตาของแมป แสง และกล้อง
- ท่าเต้น: ใช้ Animation ID ท่าเต้นมาตรฐานของ Roblox 3 ตัวใน `Config.DanceAnimations` ซึ่งยังไม่ได้ยืนยันว่าโหลดได้
  ถ้าโหลดไม่ได้ ตัวละครจะโยกตัวขึ้นลงแทน
- การส่งข้อความผ่าน MessagingService จากตัวกลางเข้าเกมที่เผยแพร่แล้ว และการเชื่อมต่อไลฟ์ TikTok จริง
- การควบคุมกล้องด้วยจอยเกม/คีย์บอร์ด/เมาส์ (ตรวจแค่การคำนวณมุมกล้อง ไม่ได้ตรวจการรับอินพุตจริง)
- หน้าตาเอฟเฟกต์ (หัวใจใช้ตัวอักษร ♥ ถ้าไม่แสดงให้บอก), การขยายตัวละคร (`Model:ScaleTo`) ขณะเล่นท่าเต้น และแสง Future บนเครื่องที่ไม่แรง

## โครงสร้างโฟลเดอร์
| ที่ | คืออะไร |
|---|---|
| `build/DanceStage.rbxlx` | ไฟล์เกมสำเร็จรูป (สร้างจาก `tools/`) |
| `src/server/` | สคริปต์ฝั่งเซิร์ฟเวอร์: คิว, เวที, ธีม, เอฟเฟกต์, รับข้อความจากตัวกลาง |

## ตัวกลาง TikTok (`bridge/`) แอปรันในเครื่อง

### เปิดแอป (แนะนำ)
1. ติดตั้ง Node.js 20+ แล้วรัน `cd bridge && npm install` (ครั้งแรกครั้งเดียว)
2. รัน `npm run app` แล้วเปิด http://localhost:3939 (ถ้าพอร์ตชน ใช้ `PORT=3940 npm run app`)
3. กรอกชื่อ TikTok ที่กำลังไลฟ์, Universe ID, Open Cloud API key แล้วกด **บันทึกค่า**
4. เริ่มด้วย **โหมดทดลอง** (ติ๊กไว้) กด **เริ่ม** ดู log ว่าอ่านแชท/ของขวัญได้ถูก แล้วค่อยปิดโหมดทดลองเพื่อส่งเข้าเกมจริง
5. ปุ่ม **ทดสอบฝั่งเกม** ส่งคนเข้าเวทีหรือของขวัญปลอมเข้าเกมได้โดยไม่ต้องรอไลฟ์
6. การ์ด **ธีมแมป** เปลี่ยนธีมของแมปในเกมระหว่างไลฟ์ได้ (รายชื่อธีมอ่านจาก `Themes.luau` อัตโนมัติ)

ค่าที่กรอกถูกเก็บใน `bridge/config.json` บนเครื่อง (ไฟล์นี้ไม่ขึ้น git) หน้าเว็บรับคำขอเฉพาะจากเครื่องเดียวกันเท่านั้น และไม่ส่ง API key กลับไปที่เบราว์เซอร์

### สร้าง API key
สร้างที่ https://create.roblox.com/dashboard/credentials เปิดสิทธิ์ **Messaging Service: Publish** ให้ experience ของคุณ

### โหมดคำสั่ง (ไม่มีหน้าเว็บ)
คัดลอก `.env.example` เป็น `.env` แล้วรัน `npm run dry-run` (ทดลอง) หรือ `npm start` (ส่งจริง)

### หมายเหตุ
- เกมต้อง **เผยแพร่ (Publish)** แล้ว และมีเซิร์ฟเวอร์ที่เปิดอยู่ เพราะ MessagingService ส่งเข้าเซิร์ฟเวอร์สดเท่านั้น
- กติกา: คนดูพิมพ์ชื่อ Roblox ตรง ๆ หรือ `!join ชื่อ` ในแชท, ตรวจว่ามีชื่อนี้จริงผ่าน Roblox API, 1 ครั้งต่อคนต่อ 60 วินาที, ของขวัญแบบกดรัวนับเมื่อจบสตรีค สูงสุด 5 ครั้งต่อชุด
- รันเทสต์: `npm test`
